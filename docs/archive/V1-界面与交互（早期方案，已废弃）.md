# GamePanl V1 界面与交互

> V1 唯一规格 · 2026-09-24。本文取代此前全部模块稿；与本文冲突的旧写法一律作废。

## 0. 说明

### 0.1 V1 目标

GamePanl 是给个人独立游戏开发者用的 macOS 桌面客户端（Electron）。它把做游戏时的创意和资源处理成四个状态：

- **放进去**：任何时候按一个键就能记下点子、截图、参考图；已有的乱文件夹可以一次导入。
- **理清楚**：收件箱逐条整理，按支柱、方面、实体归位；搁置和砍掉的东西有固定去处。
- **用得上**：实体卡串起草图、AI 候选、定稿和资产表；规格和风格词在任何地方点一下就能复制。
- **不跑偏**：主题和支柱一直显示在顶栏；整理时问"服务哪条支柱"；今日焦点最多 3 件。

边界：

- 不对接任何外部服务。图由用户自己在 GPT / Gemini 网页里生成，面板只负责"打包复制、粘回归档"。
- 以 2D 为主，兼顾 3D。引擎（Godot / Cocos）只是使用背景，V1 不读写引擎工程。草图由用户自己用数位板画。
- 所有数据都是本地项目文件夹里的普通文件，在访达里也看得懂（第 9 章）。

### 0.2 验收标准

在同一个项目里完整跑通以下四条（第 10 章逐步走查）：

1. 记点子 → 整理 → 打勾完成。
2. 画怪物 → 交给 AI → 粘回候选 → 定稿 → 进资产表。
3. 用图文导图排故事线，并链接角色和关卡。
4. 游戏截图有固定的存放位置，并且能标"可宣传"。

### 0.3 阅读方式

- **第 1 章是全局规则，只写一次**。后面各章用"→ §1.x"引用，不再重复；各章和第 1 章有出入时，以第 1 章为准。
- 第 2–8 章按模块写，每章包括：线框、核心流程、空状态 / 错误 / 边界、本页快捷键、与其他模块的衔接。
- 第 9 章是**唯一的目录表**，其他章节提到的文件位置都以它为准。第 11 章是**唯一的"不做"清单**。
- 线框里一个汉字按两个字符宽画，只示意布局和文案，不代表像素尺寸。
- 快捷键按 macOS 的顺序书写（⌃⌥⇧⌘），↵ 表示回车。界面上显示的快速记录键一律读取设置里的当前值，本文写的是默认值 ⌃⌥N。
- 示例项目统一用「雾港」：主题"守夜人提灯穿过会吞噬记忆的雾"，支柱 ①孤独感 ②光是资源 ③短局；像素横版 320×180，瓦片 16px，PPU 16，色板 Endesga 32。

### 0.4 术语

| 词 | 含义 |
|---|---|
| 条目 | 能被打开、链接、删除的东西：收件箱条目、笔记、实体、导图、画板、资产行、截图、参考图、片段 |
| 实体 / 实体卡 | 游戏里的"东西"，放在图鉴里。内置类型：角色、怪物、Boss、道具、技能、场景、关卡、界面、剧情节点、机制，也可以自定义类型 |
| 方面 | 横向的关注维度，以标签的形式挂在条目上，每个方面有一页。默认 9 个：方向、玩法、叙事、关卡、美术、音频、界面、技术与测试、发行 |
| 常驻区 | 左栏上方固定的 7 项：首页、收件箱、图鉴、资产、截图墙、参考墙、停车场 |
| 支柱 | 项目的 3 条设计支柱，整理时用来判断有没有跑偏 |
| 版本链 | 实体卡上的图片历史：草图 vN → AI 第 N 轮候选 → 修改 vN → 定稿 |
| 轮次 | 一次"交给 AI"：记下发出的文字和参考图，收回若干候选 |
| 选定 / 定稿 | 选定是在一轮候选里挑中的那张，每轮一张；定稿是整条版本链里唯一的最终图 |
| 主图行 | 资产表里由版本链自动建立的那一行，它的阶段由版本链决定 |
| 风格包 | 本项目的风格词、负面词、样张，以及"限定色板"开关（色板本身在项目规格里） |
| 项目片段 | 交给 AI 时可以勾选的文字块，分为用途、视角、约束、参考说明四类 |
| 命名尺寸 | 项目规格里带名字的 2D 尺寸，比如"角色 32×32" |
| PPU | 每单位像素数。画板网格一律取这个值 |
| 散记 | 还没有任何项目时记下的内容 |

### 1.2 顶栏

- 左起依次是：窗口按钮、左栏开关（⌘\）、后退 / 前进（⌘[ ⌘]）。
- **主题**：显示一句话主题。
  - 悬停 0.4 秒，展开 3 条支柱。
  - 点击进入「方向」方面页。
  - 没写主题时显示灰字"写下一句话主题…"；没写支柱时，悬停显示"还没写支柱 [去写]"。
- **收件箱 N**：显示待整理的条数，点击进入整理模式；为 0 时不显示数字。
- **[⌘K 搜索]**：点击等于按 ⌘K。最右边是右栏开关（⌥⌘I）。
- 顶栏本身也是投放区，从访达拖到这里的文件进收件箱（→ §1.8）。

### 1.3 左栏

- **项目切换器**在最上方（→ §2.5）。
- **常驻区** 7 项，顺序固定，对应 ⌘1–⌘7：首页、收件箱、图鉴、资产、截图墙、参考墙、停车场。收件箱和停车场显示数量（停车场只数「以后再说」和「下一作」）。
- **方面**：默认 9 个，按左栏顺序对应 ⌥⌘1–⌥⌘9。
  - 可以拖动调整顺序。
  - 右键可以隐藏，隐藏后底部显示"已隐藏 N 个"，点开可以恢复。
- **导入进度**：导入进行中时，底部显示"导入中 120/342"，点击查看明细。
- **最底一行**固定为「库 · 回收站 N」。点"库"进入库页（⇧⌘L），点"回收站"进入回收站（→ §1.12）。
- ⌘\ 让左栏在"展开"和"图标条"之间切换。
- 左栏的每一项都是投放区（→ §1.8、§1.9）。

### 1.4 右栏

- **固定四段，顺序不变**：属性、被引用处、相关规格、相关风格词。
  - 被引用处的规则见 §6.6。右栏里是紧凑列表，最多 5 条，后面接"共 N 条 ›"。
  - 规格和风格词点一下就复制，并提示"已复制"。
- **没有当前条目时**显示项目速览：分辨率、瓦片、PPU、命名尺寸、色板，以及风格词。
- **开关**：只用 ⌥⌘I。自动收起的情况见 §1.1，手动开关优先。
- **属性段**：各类型的专属信息都放在"属性"段，不另开新段。
  - 资产：提示词（附工具、日期和 [复制]）、源文件路径和修改时间、按规则生成的文件名预览。
  - 截图：日期、版本、关卡 / 系统、卖点。
  - 导图节点：状态、所在路径、节点里的链接。
- **⇧⌘点击链接**：右栏顶部临时显示目标条目的预览（标题、状态、图、正文前几行），附 [打开 ⌘O]。选中别的东西后，右栏恢复四段。

### 1.6 新建

**⌘N 在当前页新建本页的主类型**：

| 页面 | ⌘N |
|---|---|
| 首页、方面页、全部笔记 | 新建笔记并打开。在方面页新建时自动带上该方面标签 |
| 收件箱 ·「待整理」 | 光标跳到顶部的"记一条…"输入行，新建一条收件箱条目 |
| 图鉴 | 新建实体，类型取当前分组的类型；没有分组时先选类型 |
| 资产表 | 新建占位行 |
| 截图墙、参考墙 | 打开文件选择对话框 |
| 导图编辑器 | 新建导图（先选模板） |
| 画板 | 打开「新建画布」对话框 |
| 库 ·「项目片段」 | 新建片段 |

- **⌘K 里新建**统一用「+类型 名称」，比如 `+怪 雾妖`。类型可以用简写或拼音首字母（`+gw 雾妖`）。↵ 创建并打开，⌥↵ 创建但不跳转。「新建…」这样的中文前缀不算命令；不带 + 时，结果末尾固定的"新建"组已经够用。
- **创建对话框**里：↵ 创建并打开；⌘↵ 创建后只清空名称，方便接着建下一个。
- **行内新建**（[[ 补全、导图升级为实体卡、⌘K 末尾的新建组）：只需要填名称，光标留在原处。
- 新条目的状态一律是「想法」。
- 同类型下重名时，提示「打开已有 / 仍然新建（自动加后缀）」。

### 1.7 粘贴（⌘V）按落点

- **光标在文本里**：图片插入为图片块，文字照常粘贴。
- **焦点不在文本里**：由落点决定去向。

| 落点 | 粘贴图片的结果 |
|---|---|
| 截图墙 | 新截图，放在当前版本组的最前面 |
| 参考墙 | 新参考图；剪贴板里带网页地址时，自动填进"来源" |
| 资产表 | 新行；选中某一行时，挂到这一行（替换原有文件，旧文件进回收站）。选中的是主图行时，图片改为进该实体的版本链（同"实体卡"落点），主图文件仍只由定稿生成 |
| 实体卡（卡片层） | 进版本链：有进行中的轮次就成为 AI 候选；没有就成为草图，提示条附"改为 AI 候选" |
| 导图里选中的节点 | 成为节点配图；节点已经有图时，新建一个子节点放这张图；如果是引用节点，图进该实体的版本链 |
| 画板 | 新图层；⇧⌘V 作为底图 |
| 交给 AI 面板和小窗 | 本轮候选 |
| 首页、方面页、全部笔记、收件箱、停车场 | 这些页面没有图片容器，新建一条收件箱条目 |

- 焦点不在文本里时粘贴**文字**：在导图里按缩进生成节点树；在其他页面新建一条收件箱条目。
- 每次粘贴后，底部提示「已加入 X · ⌘Z 撤销 · 改为…」。
- 按内容哈希判断重复，重复时提示「已在 X · 跳到它」，不重复收下。

### 1.8 从访达拖入

- **落点规则和粘贴相同**。另外：
  - 拖到左栏的收件箱、截图墙、参考墙、资产：存进那一项。
  - 拖到左栏"图鉴"：弹出新建实体浮层的选类型步骤，每个文件建一张卡，文件作为草图 v1。
  - 拖到左栏的某个方面：进收件箱，并带上该方面标签。
  - 拖到顶栏、首页、停车场或 Dock 图标：进收件箱。
- **复制还是引用**：
  - 成品格式默认复制进项目：png jpg gif webp mp4 mov wav ogg mp3 ttf otf。
  - 源文件格式默认只存引用：aseprite psd kra clip blend glb fbx。
  - 其他格式照样收下，默认复制，显示格式图标。
  - 按住 ⌥ 可以在复制和引用之间切换，光标旁显示"复制"或"引用"。
- **文件夹**：一律打开导入设置（→ §2.4）。唯一的例外是拖到资产表已有的一行上，这时把文件夹作为素材包引用挂到这一行。快速记录浮窗不接收文件夹。
- 一次拖入多个文件时，每个文件各生成一条，并且全部保持选中。

### 1.9 在面板里拖动条目、拖出面板

| 拖到 | 结果 |
|---|---|
| 左栏的某个方面 | 加上该方面标签 |
| 左栏的停车场 | 弹出停车场小窗（→ §3.5），默认「以后再说」，按 ↵ 一步确认 |
| 笔记或实体的正文 | 生成 [[链接]] |
| 导图 | 生成引用节点（拖到节点上成为它的子节点，拖到插入线上插在那个位置） |
| 画板的画布区域 | 作为底图（→ §5.4）；拖到图层面板则作为新图层 |
| 访达、浏览器、引擎 | 拖出的是原文件本身，选中几条就拖出几个文件 |

- 在画布类页面里平移：导图里拖动空白处或双指滑动；画板里按住空格拖动或双指滑动。
- 按住 ⌥ 拖动导图节点是复制。

### 1.10 [[链接]]

- **触发**：输入 `[[`，或在中文输入法下输入 `【【`，弹出补全；输入法还在组词时不弹出。
- **搜索范围**：笔记、实体、导图、资产、片段、「项目规格」，另有一组"导图节点"（显示节点路径，→ §6.3）。
- **匹配**：可以按名称、别名或拼音首字母匹配（输入 hy 能找到"灰鸦"）。
  - 最多显示 8 条：先排本文档最近链接过的，再排最近编辑的。
  - 每一行显示：类型图标或缩略图、名称、类型、方面、状态标记。
  - 最后一行固定是「＋ 新建「xx」」，按 → 选类型（笔记或某种实体类型），属于行内新建（§1.6）。
- **保存**：链接按条目 id 保存，目标改名后，各处的显示文字自动同步。
- **点击**：
  - 在可编辑的文本里（笔记正文、实体正文、导图节点）：单击放光标，⌘点击跳转，⇧⌘点击在右栏打开（§1.4）。
  - 在只读的位置（右栏、预览卡、被引用处列表）：单击就跳转。
- **悬停** 0.5 秒弹出预览卡：定稿图或最新一张图、正文前 3 行、类型和状态。
- **复制为链接**：在任何条目上按 ⌥⌘C，粘进正文生成链接，粘进导图生成引用节点。
- 链接标签的外观见 §1.11。

### 1.11 状态：外观与切换

**哪些东西有状态**：笔记和实体有通用状态。导图节点的状态是可选的，引用节点显示所引用实体的状态。资产行只显示制作阶段，通用状态由阶段推出：占位对应待做；草图、AI 稿、修改对应进行中；定稿、已进工程对应完成。截图、参考图、片段、导图本身没有状态。

**统一外观**：同时用颜色和形状区分，不只靠颜色。清单里的圆圈、画廊的角标、导图的色条、链接标签都用这一套。

| 状态 | 标记 |
|---|---|
| 想法 | 灰色空心圆（细线） |
| 待做 | 蓝色空心圆（粗线） |
| 进行中 | 橙色半圆 ◐ |
| 完成 | 绿色实心圆带 ✓ |
| 搁置 | 灰色斜纹，加停车标记 |
| 砍掉 | 半透明，加删除线（整个应用里只有"砍掉"用删除线） |

线框里用 ○ 表示空心圆（想法或待做，旁边会写状态名），◐ 表示进行中，✓ 表示完成。

链接还有两种特殊样子：

- **目标在回收站**：灰色、垃圾桶图标，加 [恢复]。
- **目标还没创建**：虚线框，点击后选类型（默认笔记），↵ 创建。

**切换状态**：

- ⇧⌘S 打开状态菜单，在菜单里按 1–4 选想法、待做、进行中、完成。
  - 选「搁置…」打开停车场小窗，预选「以后再说」。
  - 选「砍掉…」打开停车场小窗，预选「已砍」，光标停在原因框里。
- **打勾**：按 ⌘↵ 或点圆圈就是完成，再按一次恢复到打勾前的状态。任何状态都能直接打勾。
  - 清单里打勾后，这一行变成绿勾、文字变淡，停留 2 秒（期间再点可以取消），然后滑进底部折叠的"已完成"组。
- 在导图和清单里，焦点不在输入框时可以直接按 1–4 设状态，顺序和菜单一致。
- 看板里把卡片拖到「完成」列，等于打勾。
- 在资产上按 ⇧⌘S，打开的是制作阶段菜单。
- 正文里的勾选框只是子步骤，不改变条目的状态。
- 停车场里的条目不显示圆圈；在上面按 ⌘↵ 直接标为完成，同时离开停车场，提示「已完成 · ⌘Z 撤销」。
- 砍掉的条目在各列表里默认隐藏（筛选里勾"含砍掉"才显示），在 ⌘K 里灰显；集中查看的地方是停车场的「已砍」页签。

### 1.12 删除与回收站

- **⌘⌫**（焦点不在文本里时）：把条目或文件移进回收站，不弹确认框。
  - 底部提示「已移到回收站 · ⌘Z 撤销」。
  - 被删的东西还被别处引用时，提示里加一句「被 N 处引用」。
  - 删除引用时只删记录，提示里写明「原文件未动」。
- **单独按 ⌫**：只删文档内部的元素（导图节点、正文块、图层、标签块），以及整理模式里的当前这一条。
- **需要确认的删除操作**只有：永久删除和清空回收站；删除当前定稿（先问改用哪张）；删除还有实体的类型。其他需要确认的操作（按规则重命名、一次性大量创建）见 §1.19。
- **回收站**：
  - 就是项目文件夹里的 `_trash/`，保留 30 天。
  - 同一次删除的内容归为一组，可以恢复或永久删除；恢复时原位置已经不在，就恢复到收件箱。
  - 入口有两个：左栏最底一行「库 · 回收站 N」，以及项目下拉菜单。

```
┌ 回收站 · 保留 30 天 ─────────────────────────────────────────────────────┐
│ 9/24 14:32  删除 1 项                              [恢复]  [永久删除]      │
│   分裂史莱姆      实体     codex/monster/    12.4 MB   还剩 30 天          │
│ 9/23 21:10  删除 3 项（整理收件箱）                [恢复]  [永久删除]      │
│   灯油耗尽的音效  收件箱条目  inbox/           0.1 MB                       │
│   …                                                                        │
│                                                          [清空回收站]      │
└────────────────────────────────────────────────────────────────────────────┘
```

### 1.13 选中与多选

- 单击选中，右栏显示它的属性。↵ 或双击打开。
- ⌘点击加选，⇧点击连选，⌘A 全选。
- 在画廊空白处拖出选框可以框选；导图里要按住 ⌥ 拖，因为在导图空白处拖动是平移。
- 导图例外：⌘点击是打开引用节点或跳转链接（§1.14），多选改用 ⇧点击逐个加选，或者按住 ⌥ 在空白处拖出选框。
- **批量操作栏**：选中 2 条及以上时，底部浮出批量操作栏，提供改字段、打标签、挂到实体、放进停车场（只对有状态的条目）、删除；资产表另有"按规则重命名""在访达中显示"。批量操作不问支柱。
- **空格快速预览**：看大图、播放、试听；←→ 切换，Esc 关闭。在快速预览和大图查看里按单字母，只作用于正在看的这一张。导图是例外，空格是进入编辑。

### 1.14 打开、跳转与返回

- 在清单、画廊、表格（行选中时）里，按 ↵ 或双击打开条目。
- 在 ↵ 另有用途的地方（导图、正文、正在编辑的表格单元格），用 ⌘O、双击或 ⌘点击打开。
- 外部文件和源文件按 ⌘O 用默认程序打开，⌥⌘R 在访达中显示。
- 每次跳转都记进后退记录。按 ⌘[ 返回时，恢复原来的视口、滚动位置和选中项。
- 从被引用处跳进导图时，那个节点居中并闪烁；它的上级节点如果是折叠的，先自动展开。跳进笔记时，直接定位到那一段。

### 1.15 保存与外部修改

- **全部自动保存**：停手约 1 秒后保存；画板每落一笔后 1.5 秒保存。角落显示「已保存」。
- **写入方式**：先写临时文件，写完再替换原文件。
- **写入失败**：出现红条和 [重试]，改动先留在内存里。
- **文件在外部被修改**：
  - 面板里没有未保存的改动：静默重新载入。
  - 有冲突：黄条，只给两个选项，[载入外部版本] 和 [保留我的]。
  - 文件解析失败：以只读方式打开，并说明是哪一行出错。
- **引用的外部文件找不到**：显示「找不到文件 · 重新定位」。重新定位一个文件后，同一个旧目录里其他丢失的文件自动找回。
- **在访达里新放了文件**：页面顶部提示「发现 N 个未登记的文件 [登记]」。
- **在访达里删了文件**：对应的条目标为「文件缺失」，不自动删除这条记录。
- **索引 JSON 损坏**：自动改用 `.gamepanl/` 里的上一份备份，并告诉用户哪个时间点之后的改动丢了。
- **项目文件夹在打开期间丢失**：主区出现红条「已切到只读」，文件夹恢复后自动消失。
- **个别文件读不了**：项目照常打开，提示「N 个文件无法读取」。

### 1.16 去重与重名

- 图片和文件一律按内容哈希去重。粘贴或拖入重复的内容时，提示「已在 X · 跳到它」；导入时默认勾选「重复只留一份」。
- 文件重名时，自动在名字后加 `_02`（依次递增）。
- 同类型的条目重名时，提示「打开已有 / 仍然新建（自动加后缀）」。
- 导图节点升级为实体卡时遇到重名，提示「改为引用已有的」。

### 1.17 图片显示

- **像素图**在所有地方（缩略图、预览、对比、导图节点）都用最近邻缩放，透明处显示棋盘格。
  - 像素图指：来自像素画布的图，以及长边 ≤256 的图。
  - 其他图片可以右键「按像素图显示」手动切换。
- **缩略图**在后台生成，缓存在 `.gamepanl/` 里；生成之前，按原图比例显示灰块。
- **尺寸标记**：每张图都能显示像素尺寸。和它引用的规格不符时标 ▲（比如"▲ 1024≠32"），只提示，不拦截。

### 1.18 文件命名

- **规则只在项目规格里定义一处**：`{前缀}_{文件名ID}_{动作}_{序号}`，另有可选段 `{方向}`，启用后是 `{前缀}_{文件名ID}_{动作}_{方向}_{序号}`。
  - 某一段为空时，连同它前面的下划线一起省略。
  - 序号是两位数，从 01 开始，同名已存在时递增。
- **前缀按资产类型区分**（前缀表可以在规格页修改）：

| 资产类型 | 前缀 | 存放目录 |
|---|---|---|
| 图片 | spr | `assets/sprites/` |
| 动画 | anim | `assets/anims/` |
| 特效 | fx | `assets/fx/` |
| 音效 | sfx | `assets/sfx/` |
| 字体 | font | `assets/fonts/` |
| 素材包 | pack | `assets/packs/` |

- **{文件名ID}**：只取实体卡上唯一的「文件名 ID」字段。
  - 新建实体时自动给出拼音建议（分裂史莱姆 → fenlieshilaimu），可以改成英文。
  - 没手动改过之前，它跟着名称自动更新。
  - 资产行没挂实体时，这一段为空，文件保留原名，行上显示灰色的"建议名"。
- **适用范围**：只有进资产表的文件才按这条规则命名，例如 `spr_fenlieshilaimu_01.png`、`anim_fenlieshilaimu_hit_01.png`。
  - 版本链内部的文件（草图、AI 候选、修改）用简单的序号命名（§9）。
  - 截图用"shot_月日-时分_版本"（如 shot_0922-1403_v0.3.png），拖入的截图保留原文件名；参考图保留原文件名，粘贴的叫"ref_月日-时分"（如 ref_0924-1432.png）。
  - 导入的文件保留原名。
- **规则改了只影响之后的新文件**，已有文件不会自动改名；改实体的文件名 ID 也不会自动改任何文件。
  - 需要改名时，在资产表选中行，点批量栏的「按规则重命名」。
  - 它会先列出新旧文件名让用户确认；已进工程的资产和所有源文件会被跳过，永远不会被自动改名。

### 1.19 用撤销代替确认

- 移动、归类、挂载、升级为实体卡、批量操作、拉回已砍的条目都立即生效，不弹确认框。
  - 底部提示条给出 ⌘Z 撤销和「改为…」快速修正。
  - 提示条停留 6 秒，鼠标悬停时不消失；提示条消失后，⌘Z 仍然有效。
- **需要确认的只有**：
  1. 永久删除、清空回收站。
  2. 删除当前定稿：先问改用哪张做定稿。
  3. 按规则重命名文件：先列出新旧文件名。
  4. 删除还有实体的类型：先选这些实体改成哪个类型。
  5. 一次性大量创建：一次粘贴超过 50 行文本生成节点、一次拖入超过 50 个文件新建实体等。

### 1.20 加载与空状态

- 本地读写超过 300 毫秒，才显示加载占位；长列表只渲染看得见的部分。
- 空状态统一为一句说明，加最多三个动作按钮（比如「现在试一下」「从文件夹导入」）；有数据后就不再出现。
- 筛选没有结果时，统一显示「没有符合的条目 · 清除筛选」。

### 1.21 菜单栏与设置

- ⌘W 关闭主窗口后，应用留在菜单栏，快速记录照常可用；按 ⌘Q 才真正退出。
- 设置（⌘,）里只有这几项：
  - 快速记录键。
  - 登录时在菜单栏启动。
  - 关闭窗口或切换项目时问"停在哪里"。
  - 交给 AI 小窗自动收剪贴板里的图。

### 2.3 新建项目

按 ⌥⌘N 打开。一个面板分 4 步，只有名称必填，每一步都可以跳过。

1. **名称与位置**：位置默认是 `~/GamePanl/<project-id>/`，项目 ID 按名称自动给出拼音建议（雾港 → wugang），可以改成英文；名称本身可以用中文，只显示在界面里。维度可选 2D、3D 或两者都有，决定第 4 步显示哪些规格。
2. **主题与支柱**：一句话主题占 1 行，支柱固定 3 行，占位文字里给出例子。都可以留空。
3. **美术风格与色板**：
   - 从美术风格库里选一张卡片（样张加一句特点），也可以选"还没定"。
   - 下方选一个调色板。

### 2.4 从已有文件夹开始 / 导入

整个应用只有这一个导入界面。

**入口**：

- 启动窗或项目下拉菜单里的 [从已有文件夹开始]：导入设置之后接新建项目的 4 步，项目建好后在后台导入。
- 项目已经打开时，用菜单「文件 › 导入文件夹…」，或者把文件夹拖进窗口：直接导入当前项目。

**流程**：

1. **选文件夹**，开始扫描：显示进度和各类文件的数量，可以取消。
   - 自动跳过 `.godot` `.import` `library` `temp` `.git` 这些目录，以及 `.meta` 文件。
2. **导入设置**：

```
┌ 导入文件夹 ~/Desktop/旧项目 · 已扫描 1,284 个文件 ─────────────────────────────────┐
│ 子文件夹             内容           去向                   方式                   │
├───────────────────────────────────────────────────────────────────────────────────┤
│ ☑ ▾ art/             412 图片       资产 ▾                 复制                   │
│ ☑    └ src/          37 源文件      资产 ▾                 引用 ▾（引用/复制进项目）│
│ ☑ ▸ screenshots/     88 图片        截图墙 ▾               复制                   │
│ ☑ ▸ ref/             120 图片       参考墙 ▾               复制                   │
│ ☑ ▸ notes/           58 文本        笔记 ▾                 复制                   │
│ ☑ ▸ packs/           3 压缩包       资产·素材包（引用）▾   引用                   │
│ ☐ ▸ misc/            9 混合         收件箱 ▾               复制                   │
│   .godot/ .import/ .git/ library/ temp/ .meta 等 509 个：已自动跳过               │
├───────────────────────────────────────────────────────────────────────────────────┤
│ ☑ 子文件夹名作为标签    ☑ 重复只留一份（23）    文件一律保留原名                  │
│ 将复制 1.3 GB，磁盘剩余 48 GB                   [取消]   [下一步：建项目 ↵]        │
└───────────────────────────────────────────────────────────────────────────────────┘
 项目已经打开时，右下按钮是 [导入 724 项]。
```

   - **行**：默认按一级子文件夹成行，点 ▸ 可以展开下级，给下级单独改去向。
   - **去向**：自动判断，每行都可以改。只有判断不了的才进收件箱。

     | 条件 | 去向 |
     |---|---|
     | 文件夹名含 screenshot、shot、截图 | 截图墙 |
     | 文件夹名含 ref、reference、参考 | 参考墙 |
     | 以 .md / .txt 为主 | 笔记 |
     | 图片、音频、字体、源文件、其他未知格式 | 资产（未知格式显示格式图标，可以用默认程序打开） |
     | 压缩包、用户手动指定的整包文件夹 | 资产·素材包（引用） |
     | 混合、判断不了 | 收件箱 |
     | 用户选择 | 跳过 |

   - **方式**：成品文件复制；源文件那几行给出「引用 / 复制进项目」两个选项，默认引用。原文件夹不会被修改。
   - **文件名**：一律保留原名，导入时不改名。以后需要时，在资产表的批量栏用「按规则重命名」。
   - **标签**：子文件夹名作为标签，重复的只留一份。整批内容另带一个标签「导入:旧项目」，方便筛选。
   - 去向是收件箱的超过 50 条时，提醒"建议直接分到墙、资产或笔记"。
   - 导入前先估算需要的磁盘空间，不够就不开始。
3. **（仅从文件夹开始时）新建项目 4 步**：名称预填为文件夹名，其余同 §2.3。按 ⌘↵ 创建后进入首页。
4. **后台导入**：进度显示在左栏底部（"导入中 120/342"），期间可以正常使用面板。
5. **完成摘要**（底部提示条，不自动消失）：
   - 「导入 724 · 重复 23 · 失败 2 [查看] [撤销本次导入]」。
   - 有源文件仍在原目录时，追加一行「37 个源文件仍在 ~/Desktop/旧项目，移动或删除这个文件夹会断开链接 [全部复制进项目]」。
   - [查看] 列出失败的文件和原因。
   - [撤销本次导入] 把这一批全部移进回收站。
6. **导入之后的整理**：
   - 在收件箱里多选，批量留下、放进停车场或删除。
   - 在资产表「未挂实体」分组里多选，按 E 挂到实体；实体还没建的，可以直接在 E 的搜索里"＋ 新建"。

## 3. 快速记录浮窗、收件箱与整理模式、笔记、停车场

### 3.1 快速记录浮窗

在任何应用里按 ⌃⌥N 呼出。浮窗宽 480，出现在当前屏幕上方约 1/4 处，能盖在全屏应用上面，光标直接在输入框里。

```
┌──────────────────────────────────────────────────────────────┐
│ 记到 [雾港 ▾]                             去向 [收件箱 ▾]    │
│                                                              │
│ Boss 二阶段地面会塌，要跳平台                                │
│ 每圈间隔 3 秒_                                               │
│ ──────────────────────────────────────────────────────────── │
│ [缩略图 ×]  [敌人.aseprite · 引用 ×]                          │
│ 来自：第3关 / 关卡  ×                                        │
│ ↵ 保存  ⌘↵ 保存再记  ⇧↵ 换行  ⌘T 去向  ⌘P 项目  Esc 收起     │
└──────────────────────────────────────────────────────────────┘
```

**能做的事**：浮窗只做这些：写文字、粘贴或拖入附件、选去向、选项目。

- **文字**：第一行是标题，其余是正文，⇧↵ 换行。
- **粘贴（⌘V）**：
  - 图片进附件栏，文字插入输入框。
  - 在访达里复制的文件作为附件。
  - 剪贴板里同时有图和文字时，两样都收。
  - 粘贴网址时存为链接文字，不去抓取网页标题。
- **拖入文件**：按 §1.8 决定复制还是引用。拖入文件夹时不接收，提示"文件夹请用「文件 › 导入文件夹…」"。
- **去向**：下拉菜单 [收件箱 | 截图墙 | 参考墙]，⌘T 在三者之间循环。
  - 10 分钟内记住上次选的去向，超过 10 分钟回到收件箱。
  - 去向是截图墙或参考墙时，每张图各生成一张卡。文字作为截图的"备注"，或参考图的"参考它什么"。不是图片的附件和没有图片的内容仍然进收件箱，提示里写明。
- **项目**：默认存到最近用过的项目，⌘P 换项目。
- **来自**：GamePanl 在前台时呼出浮窗，底部显示当前位置的上下文标签，比如"来自：第3关 / 关卡"，可以点 × 去掉。保存时：
  - 自动带上这个方面标签。
  - 当前条目是实体时，预填"挂到"这个实体（去向是截图墙时写进"关卡 / 系统"）；是笔记或导图时，在正文末尾加一行"来自 [[第3关]]"。
  - 整理时，A 和 E 已经预填好。
- **保存**：
  - ↵ 保存：提示「已记入 雾港 · 收件箱 13」，0.6 秒后消失，焦点回到原来的应用，顶栏数字加 1。
  - ⌘↵ 保存后清空输入框，浮窗不关，接着记下一条。
- **收起**：Esc 收起浮窗，没保存的内容留作草稿，下次呼出时还在。

**边界**：

- 内容为空时按 ↵：浮窗轻轻晃一下，不保存。
- 只有图片没有文字时，标题自动设为"图片 · 9/24 14:32"。
- 还没有任何项目时，"记到"显示为 [散记]，照样能记。内容存为散记，建好第一个项目后自动并入它的收件箱。
- 目标项目不可用（文件夹丢失）时：显示红字和 [换项目]，已输入的内容不丢。
- 保存失败时：窗口不关，红字"没存上：原因 · [重试] [复制文字]"，草稿保留。
- 截图可以用系统的 ⌃⇧⌘4 截到剪贴板，再在浮窗里 ⌘V。

### 3.2 收件箱页

收件箱页有两个页签：[待整理] 和 [全部笔记]。按 ⌘2 进入待整理，再按一次切到全部笔记。

```
┌ 收件箱 ─────────────────────────────────────────────────────────────────────┐
│ [待整理 12] [全部笔记]                     [导入文件夹…]  [开始整理 ⇧⌘I]    │
│ ┌ 记一条…（⌘N）───────────────────────────────────────────────┐             │
│ 今天                                                                        │
│  文  Boss 二阶段地面会塌，要跳平台     关卡 · 挂到 第3关       14:32         │
│  图  [缩略图] 图片 · 9/24 14:10                                14:10         │
│ 更早                                                                        │
│  件  敌人.aseprite（引用）                                    放了 9 天      │
└─────────────────────────────────────────────────────────────────────────────┘
```

- 条目按时间倒序排列，行首的"文 / 图 / 件"表示内容类型。
- 右栏的属性段显示：来源（浮窗、粘贴、拖入、导入）、时间、附件数。
- 超过 7 天没整理的条目显示"放了 N 天"，不弹窗打扰。
- 可以多选后批量留下、放进停车场、删除、挂到实体，主要用于处理批量导入的内容。批量操作不问支柱。
- 在这个页面粘贴或拖入，都新建收件箱条目。

### 3.3 整理模式

**入口**：顶栏收件箱数字、首页"待整理"、收件箱页的按钮，或 ⇧⌘I。

进入后主区全屏，左右两栏收起，顶部一直显示主题和支柱。一次处理一条，从最早的开始。

```
┌ 守夜人提灯穿过会吞噬记忆的雾   ①孤独感 ②光是资源 ③短局 ─────────────── 3 / 12 ┐
│ Boss 二阶段地面会塌，要跳平台                              14:32 · 浮窗         │
│ 每圈间隔 3 秒                                                                  │
│ [图片]                                                                         │
│ 相似：停车场·已砍「Boss 场地破坏」3/12，原因：工作量太大                        │
├────────────────────────────────────────────────────────────────────────────────┤
│ 服务哪条支柱？  [1 孤独感] [2 光是资源] [3 短局]    0 都不是 · 不按 = 未标      │
│ 顺手：E 挂实体 [第3关 ×]   A 方面 [关卡 ×]   L 留作 [笔记]   D 设为待做         │
│       ⌘J 加入焦点（18 点后默认明天）                                            │
├────────────────────────────────────────────────────────────────────────────────┤
│    ↵ 留下       P 停车场       ⌫ 删除       → 稍后       ⌘Z 撤销    Esc 退出   │
└────────────────────────────────────────────────────────────────────────────────┘
```

1. **改文字**：按 Tab 进入标题或正文改几个字，Esc 退出编辑。
2. **标支柱**（可选）：
   - 按 1 / 2 / 3，可以多选，再按一次取消。
   - 按 0 表示哪条都不服务，这时 P 键高亮，提示"考虑停车场"。
   - 不按就记为"未标"。项目还没写支柱时，这一行不出现。
3. **挂实体**（可选）：按 E 搜索图鉴，↵ 挂上；也可以在搜索末行"＋ 新建「xx」"，按 → 选类型。
4. **方面**（可选）：按 A 打字筛选，↵ 添加，可以加多个。
5. **留作**（条目里有图片时才有）：按 L 在 笔记 / 参考图 / 截图 / 资产 之间循环。
   - 参考图：每张图进参考墙，文字作为"参考它什么"。
   - 截图：每张图进截图墙，文字作为备注，版本取当前版本。
   - 资产：每张图生成一条占位资产行，挂上这张图；如果按 E 挂了实体，它就是这一行的所属实体。
   - 纯文字的条目只能留作笔记。
6. **顺手**：D 让留下后的状态是「待做」，而不是「想法」；⌘J 加入焦点（→ §2.7）。
7. **做决定**：
   - **↵ 留下**：按"留作"去向处理。留作笔记时，条目变成笔记（默认想法状态），从 `inbox/` 移到 `notes/`，出现在「全部笔记」里。
   - **P**：在原处展开停车场小窗（§3.5）。确认后，条目变成笔记（状态为搁置或砍掉），从 `inbox/` 移到 `notes/`，不再计入待整理。收件箱页批量"放进停车场"同理。
   - **⌫**：进回收站。
   - **→ 稍后**：这条移到队尾。
   - 每一步底部都有提示，比如「已留下 · ⌘Z 撤销」，下一条从侧面滑入。
8. **Esc**：退出整理，下次从剩下的开始。

**"留下并挂到实体"的含义**：笔记保持独立，内容不会复制到实体卡里。它只出现在该实体"被引用处"的「挂在这里」一组（§6.6），在那里可以直接打勾。

**相似提示**：用标题在笔记和停车场里做模糊匹配，找到时显示一行"相似：…"，点击在右栏打开。

**清空后显示小结屏**：

```
┌ 收件箱清空了 ────────────────────────────────┐
│ 留下 8 · 停车场 2 · 删除 2 · 未标支柱 3       │
│ 已加入明天的焦点 1                            │
│                                               │
│        [回首页]      [选明天的焦点]           │
└───────────────────────────────────────────────┘
```

18 点以前，第二个按钮是 [选今日焦点]。

### 3.4 笔记

「全部笔记」使用第 8 章的条目表通用外壳：默认清单视图，也可以切到表格或看板（看板按状态分列）。

```

**笔记编辑器**：

```
┌ 全部笔记 › Boss 二阶段地面会塌 ──────────────────────────────┬ 右栏 ──────────────┐
│ ○ Boss 二阶段地面会塌，要跳平台                       已保存 │ 属性               │

- **块编辑器**：
  - 输入 `/` 打开块菜单。
  - 行首输入 `#`、`-`、`[]`、`>` 或三个反引号，自动转成对应的块。

  - Markdown 文本转成对应的块。
  - 选中文字后粘贴网址，这段文字变成链接。
- **拖入**：从访达拖进来的文件生成图片块或文件引用块；从面板里拖进来的条目生成 [[链接]]。

### 3.5 停车场

停车场不是一个文件夹，而是按状态筛出来的视图：搁置和砍掉的条目仍然在各自的位置（`notes/`、`codex/`…），只是会集中显示在这里。

```
┌ 停车场 ─────────────────────────────────────────────────────────┐
│ [以后再说 8] [下一作 3] [已砍 5]                 搜索三类…      │
│ 联机合作守夜         笔记   以后再说 · 9/12 · 先做单人  [拉回]  │
│ 雾妖会分裂           怪物   以后再说 · 9/10             [拉回]  │
│ Boss 场地破坏        笔记   已砍 · 3/12 · 工作量太大    [拉回]  │
└─────────────────────────────────────────────────────────────────┘
```

**停车场小窗**：整理模式里按 P、把条目拖到停车场、在状态菜单里选「搁置…」或「砍掉…」，打开的都是它。

```
┌ 放进停车场 ──────────────────┐
│ ▸ 以后再说                    │   ↑↓ 选类别
│   下一作                      │   直接打字 = 写原因（可空）
│   已砍                        │   ↵ 确定   Esc 返回
│ 原因：做完主线再看_           │
└───────────────────────────────┘
```

- 默认选「以后再说」，按 ↵ 一步确认。
- 「以后再说」和「下一作」的状态是搁置，「已砍」的状态是砍掉。
- **拉回**：点 [拉回] 或按 ⇧⌘R，条目恢复到停车前的状态，回到原来的列表，提示「已拉回 · 打开」。
  - 拉回「已砍」的条目不弹确认，提示条里写出当初砍掉的日期和原因。
- **换类别**：拖到另一个页签，或右键「改为…」。
- **搜索**：页内搜索同时查三类的标题、正文和原因。⌘K 的结果里也包括停车场的条目，并标明类别。
- 「已砍」是砍掉条目唯一集中查看的地方，能查到当初为什么砍。
- 停车场的条目不显示状态圆圈；按 ⌘↵ 可以直接标为完成并离开停车场。

### 3.6 空状态、错误、边界

- **空状态**：
  - 第一次打开收件箱："想到什么就按 ⌃⌥N，面板不在前台也能用"，加两个按钮 [现在试一下] 和 [导入已有文件夹]。
  - 全部笔记为空："收件箱里留下的会出现在这里，也可以 ⌘N 新建"。
  - 停车场三类各一句：
    - 以后再说："暂时不做的放这里，不会丢"。
    - 下一作："留给下个项目"。
    - 已砍："砍掉的东西和原因，同样的念头再冒出来时能查到"。
- **边界**：
  - 整理过程中新记的条目排到队尾，计数实时更新。
  - 笔记的 .md 在外部被修改时，按 §1.15 处理。

### 3.7 衔接

- **进来**：
  - 全局快捷键。
  - ⌘K 的新建和搜索。
  - 顶栏和首页的待整理数。
  - 首页今日焦点。
  - 批量导入（每个文件一条，只在去向是收件箱或笔记时）。
  - 方面页里新建笔记。
- **出去**：
  - 挂到实体：出现在实体被引用处的「挂在这里」。
  - 留作截图、参考图、资产：分别进截图墙、参考墙、资产表。
  - [[链接]]：跳到实体卡、资产、片段、导图或其他笔记。
  - 方面标签：笔记出现在对应的方面页。
  - 支柱标注：在全部笔记里可以按支柱筛选。

### 4.2 新建实体

一个浮层，分两步。

```
┌ 新建实体   输入筛选… ┐       ┌ ← 怪物 ─────────────────────────────────────┐
│ 1角色  2怪物  3Boss   │  ─→   │ 名称     [分裂史莱姆_____]   ← 唯一必填      │
│ 4道具  5技能  6场景   │       │ 文件名ID [fenlieshilaimu]  用于资产文件名，可改│
│ 7关卡  8界面  9剧情节点│       │ 别名     [__________]                        │
│ 机制   自定义…        │       │ 尺寸     [⇢ 小型怪物 32×32 ▾]                 │
│ 最近用过：怪物        │       │ 出现关卡 [关联…]    掉落 [关联道具…]          │
└──────────────────────┘       │ 方面 美术× 玩法×        状态 想法 ▾           │
                               │ ↵ 创建并打开     ⌘↵ 创建后再建一个            │
                               └─────────────────────────────────────────────┘
```

- **入口**：
  - 在图鉴按 ⌘N；在某个分组上点 [+] 或按 ⌘N，会跳过选类型。
  - ⌘K 里输入 `+怪 分裂史莱姆`。
  - [[ 补全末行的"＋ 新建"。
  - 导图的"升级为实体卡"。
  - 整理模式里按 E 后新建。
- **选类型**：按数字键，或打字筛选后按 ↵。数字和类型的对应关系在所有地方都一样（1 角色、2 怪物、3 Boss、4 道具、5 技能、6 场景、7 关卡、8 界面、9 剧情节点）。
- **尺寸**：下拉列出项目规格里的全部命名尺寸，以及"瓦片"和"游戏画面"（即基准分辨率）；默认值取类型模板指定的那一条（怪物 → 小型怪物，Boss → Boss，道具 → 道具图标，关卡和场景 → 游戏画面）；规格里没有这一条时，取列表第一条。选"自定义…"才能手动输入，手输的值标 ▲。
- **其他默认值**：方面标签按类型预填，状态默认"想法"。
- **创建**：↵ 创建并打开，⌘↵ 创建后只清空名称。重名按 §1.16 处理。
- **批量建卡**：把多张图从访达拖到图鉴的某个分组上，每张图建一张卡，名称取文件名，图作为草图 v1。建好的卡保持选中，方便批量打标签。超过 50 张时先确认。拖到已有的卡上，则把这些图追加为这张卡的草图版本。

### 4.4 版本链

链上的四种版本：

| 版本 | 怎么产生 | 存在哪（§9） |
|---|---|---|
| 草图 vN | 在"从草图打开或新建"的画板里按 ⌘S 冻结；在卡片层粘贴或拖入图片（没有进行中的轮次时） | `versions/sketch/vN.png` |
| AI 第 N 轮 · 候选 A/B/C | 交给 AI 后粘回、拖回或自动收回 | `versions/ai/round-N/A.png` + `round.json` |
| 修改 vN | 从 AI 候选、修改版或定稿打开的画板里按 ⌘S；"缩到规格尺寸"；"按规格重描"后存一版 | `versions/edit/vN.png` |
| 定稿 | 在任意一个版本上按 F，整条链只有一张 | 版本链里不另存，只是标记那一版；`assets/sprites/` 里生成主图文件（§4.7） |

- **草图**：
  - 同一个画板里，每按一次 ⌘S，就把当前状态冻结成只读的 vN，之后继续画的内容自动成为 vN+1。
  - 冻结时把合成图写成 `vN.png`（不含底图），同时在画板文件里记下这一版的图层快照，方便"从这一版继续画"。
- **轮次**：
  - 每次交给 AI 都在链上新开一轮，记下这些内容：发出的文字、附带的图（指向冻结的草图版本和各张参考图）、工具、时间、每张候选的收图方式（粘贴、拖入、自动收）和原始尺寸。
  - 本轮进行中时，在卡片层 ⌘V 或拖入图片，都成为本轮候选。
  - 本轮在这些情况下结束：点 [结束本轮]、开始新一轮、或 24 小时没有操作。
- **没有进行中的轮次时粘图**：默认成为草图，提示条上给「改为 AI 候选」，点了就补开一个"未记录轮次"，提示词和工具可以事后补。
- **修改**：只有从 AI 候选、修改版或定稿打开的画板，存一版时才记为修改 vN，并在版本信息里写"来源：第 1 轮 B"。从草图打开或新建的画板，存一版时记为草图 vN。
- **用外部程序打开**：先复制一份再打开。检测到外部保存后，自动记为新的修改版，提示条附「改为覆盖此版」。
- **源文件**：把 .aseprite、.psd 等源文件拖到版本区时，不进版本链，而是挂到主图资产行的"源文件"位（引用），提示里写明。版本区只收图片。
- **版本区操作**：
  - ←→ 切换版本，空格看大图，↵ 查看这一版的信息（提示词、工具、日期、来源）。
  - C 对比，F 设为定稿，X 标为落选或取消落选，B 作为画板底图，⌘⌫ 删除（进回收站）。
- **右键菜单**：
  - 草图版本：从这一版继续画 / 基于这张再来一轮 / 以此为参考交给 AI / 用外部程序打开 / 设为定稿 / 在访达中显示。
  - AI 候选、修改版、定稿：在画板里改 / 按规格重描 / 缩到规格尺寸（最近邻）/ 等分切 ▸（仅 AI 候选）/ 基于这张再来一轮 / 以此为参考交给 AI / 用外部程序打开 / 设为定稿 / 在访达中显示。
- **拖出**：从版本区拖出一张图，拖到浏览器就是发给 AI，拖到访达就是导出原图，拖到画板就是作为底图。

### 4.5 对比与定稿

```
┌ 对比 · 分裂史莱姆 · 第1轮 ─ 背景[棋盘|白|黑]  [适应 ⌘0 | 1:1 ⌥⌘0]  同步缩放 ✓   Esc ┐
│   ┌──────┐      ┌──────┐      ┌──────┐      ┌──────┐                               │
│   │草图v1│      │  A   │      │  B   │      │  C   │                               │
│   └──────┘      └──────┘      └──────┘      └──────┘                               │
│   输入草图      1024×1024 ▲   1024×1024 ▲   1024×1024 ▲   ← 和尺寸字段 32×32 对照   │
│                 [1 选定]      [2 选定]      [3 选定]                                │
│ 选定理由（可空）：[轮廓最清楚，眼睛位置对_______________]                            │
│ ↵ 确认选定      ⌘↵ 选定并同时设为定稿      Esc 关闭                                  │
└─────────────────────────────────────────────────────────────────────────────────────┘
```

- **打开**：在某一轮上按 C；或者 ⌘点选 2–4 张图再按 C。输入草图自动排在第一列，最多并排 4 张候选。
- **选定**：
  - 按数字键选定一张，光标进入理由框。
  - ↵ 确认（理由可以空着）；⌘↵ 选定并同时设为定稿，一步完成。
  - 按 Esc 关闭时不写理由，选定照样生效。
  - 选定后，同一轮的其余候选标为落选并折叠，展开后可以取消落选。
  - "选定"单独保留，用于还想再来一轮的情况。
- **背景**：点顶部按钮切换棋盘、白、黑。
- **定稿**：在任意版本上按 F，或者在对比浮层里按 ⌘↵。整条链只有一张定稿，原来的定稿改标"曾定稿"。设为定稿后：
  - 缩略图、悬停卡、导图节点，以及以后交给 AI 的默认参考图，都指向版本链里的这张定稿原图。
  - 在 `assets/` 下按命名规则生成一份文件，作为主图行的"文件"（§4.7）。实体文件夹里不另存副本。
  - 实体本身的状态不变。
- **删除当前定稿**：先问"改用哪张做定稿？"，列出其他版本，可以选"暂不定稿"。

### 4.6 AI 图的规格处理

V1 做最小版本，由版本链负责。像素项目的主路径是"按规格重描"。

- **尺寸标记**：尺寸和实体的尺寸字段不符的候选或版本，标黄色 ▲，比如"▲ 1024≠32"。
- **[按规格重描]**：按钮在黄色标记旁边。点击后：
  - 新建一张规格尺寸的像素画布，这张图以"适合画布"作为底图。
  - 进入画板，画完按 ⌘S 存为修改 vN，来源记为这张候选。
- **右键「缩到规格尺寸（最近邻）」**：直接生成一张修改 vN，适合 AI 本来就画得很接近像素风格的情况。
- **右键「等分切 ▸ 2×2 / 1×2 / 2×1」**：用于 AI 把几个方案拼在一张图里的情况，在同一轮里切出 A1–A4。
- 去背景、压到项目色板，放到 V2。

### 4.7 主图行与资产

- **自动建行**：版本链第一次有图时，资产表自动建一条"主图"行（类型：图片，所属实体：本实体，规格：本实体的尺寸字段，动作留空）。
- **阶段**：主图行的阶段等于版本链走到的最远一步，顺序是 占位 → 草图 → AI 稿 → 修改 → 定稿。
  - 这个阶段只读，旁边标"来自版本链"。只有"已进工程"要手动标。
  - 有任意一张 AI 候选，就算走到了"AI 稿"。
  - 版本全部删掉时，退回"占位"。
- **文件**：主图行的"文件"是定稿时在 `assets/sprites/` 下生成的那一份，例如 `spr_fenlieshilaimu_01.png`。
  - 换定稿时替换这个文件，旧文件进回收站。
  - 如果这一行原来是"已进工程"，阶段退回"定稿"，并提示「主图已换 · 需要重新放进工程」。
- **其他资产行**（动画、音效等）：阶段全部手动推进。
- **一张卡只有一条版本链**：动作、特效等其他图都作为资产行挂在实体上。资产行没有版本（§8.4）。

### 4.8 自定义类型与字段

1. **新建类型**：点 [+类型]，填名称，选图标和颜色，选字段来源（复制某个类型，或从空白开始），设默认方面标签和默认尺寸。
2. **字段**：
   - 可以增加、改名、拖动排序，也可以设为在画廊卡片上显示（最多 2 个）。
   - 字段类型只有 8 种：短文本、长文本、数字、单选、多选、勾选、关联实体、规格引用。
   - 名称、别名、文件名 ID、状态、方面、支柱是所有类型共有的内置字段。
3. **删除字段**：不会删掉数据，已有的值会移到"旧字段"折叠区。实体改类型时，名称和字段类型都相同的字段保留，其余的也进"旧字段"。
4. **内置类型**：也能改，改的是项目里的副本，可以恢复默认。
5. **删除类型**：类型下还有实体时，先选这些实体改成哪个类型（§1.19）。

### 4.9 空状态、错误、边界

- **空状态**：
  - 第一次打开图鉴：显示类型网格和标题"你的游戏里有什么？先建一个"，另有"从文件夹导入图片"。
  - 版本区为空：两个大按钮"画草图"和"粘贴或拖入图片"，下面一个小入口"画像素稿（32×32）"。
  - 被引用处为空："还没有地方提到它"，这张卡会出现在"无引用"筛选里。
- **错误**：
  - 版本图片被移走：显示「找不到 versions/ai/round-1/C.png · 重新定位 / 移除记录」。
- **边界**：
  - 重复粘贴同一张图：提示"已在第1轮 B"。
  - 删除实体：连同它的文件夹进回收站，提示"被 N 处引用"；指向它的链接和引用节点显示为灰色，带垃圾桶图标和 [恢复]。
  - 改名称：链接按 id 指向，各处自动同步；实体文件夹一起改名。
  - 改文件名 ID：不改任何文件，相关资产行出现"建议名"。
  - 改规格值：所有引用它的地方自动跟着变。规格条目被删掉时，字段保留原来的值，改为"自定义"并标 ▲。

- 版本区和对比浮层：见 §1.5 ③。

## 5. 画板、新建画布、交给 AI

### 5.1 画板

```

- **进入和退出**：进入画板时，左右两栏自动收起。按 Tab 隐藏或显示全部面板。
- **面包屑**：
  - 显示所属实体、画板名、当前版本。单击实体名回到实体卡（等同 ⌘[）；双击实体名或画板名进入改名，↵ 确认，Esc 取消（"未命名怪物"就在这里改）。
  - [挂到…] 可以随时更换所属实体，画板文件会一起搬过去。
- **笔刷**只内置三种：像素笔（1px、无抗锯齿）、硬边圆、软边圆。
- **压感**：设置在弹层里，包括压感控制粗细（默认开）、压感控制不透明度（默认关）、软 / 中 / 硬三条曲线，以及一条试画带。
- **像素模式**：默认用像素笔，关闭压感，只能按整数倍缩放，放大到 800% 以上自动显示像素格，默认锁色板。网格一律取 PPU。
- **色板**：取自项目规格。
  - 锁色板时，取到色板外的颜色会自动吸附到最近的色板颜色。
  - 不锁时，色块上标一个"色板外"的点。
- **复制**：V1 没有选区。按 ⌘C 复制整张合成图（不含底图），可以直接粘进导图节点、笔记或网页。
- **保存**：每落一笔 1.5 秒后自动保存，⌘S 存一版（§4.4）。
- **容量上限**：画布最大 4096×4096，最多 32 层，撤销 100 步（画板有自己的撤销栈）。

- **预设**由两部分组成：固定的"概念草图（手绘）"，加上项目规格里的命名尺寸、瓦片和游戏画面；另有"自定义"和"从规范库选…"。
- 默认选中这个实体类型上次用的预设。
- 从规范库选的尺寸默认只用于这一张；选"同时写入规格"，会作为新的命名尺寸加进项目规格。

- 画布尺寸不跟着规格变；网格如果没有手动改过，就跟着规格的 PPU 变。

### 5.3 画板存在哪、存一版记成什么

| 从哪打开 | 画板文件放在 | ⌘S 存一版记为 |
|---|---|---|
| 实体卡"画草图"、"画像素稿"；草图版本右键"从这一版继续画" | `codex/<type>/<id>/boards/` | 草图 vN |
| AI 候选、修改版或定稿右键"在画板里改"、"按规格重描" | `codex/<type>/<id>/boards/` | 修改 vN（记来源） |
| 导图引用节点右键"画草图" | 所引用实体的 `boards/` | 草图 vN |
| 导图普通节点右键"画一张" | `maps/<map-id>_images/` | 不进版本链；合成图自动成为节点配图 |
| ⌘K `+画板` 并选"不挂" | `boards/`，同时在收件箱生成一条指向它的条目 | 冻结的版本先存在画板里，挂到实体后依次成为草图 v1…vN |

- **画板文件**是一个 `<画板名>.board/` 文件夹，里面有画板描述 JSON、每层一张 PNG，以及一张预览 PNG（访达里按空格能看）。其他地方引用的都是预览图。
- **画板名**默认是"概念草图"、"像素稿"；从候选打开的叫"改-第1轮B"；重名时加 `_02`。
- 未挂实体的画板在整理时"挂到实体"，或者点面包屑的 [挂到…]，整组迁进该实体，收件箱里那一条随之移出。
- 普通节点升级为实体卡时，它的画板搬进实体的 `boards/`，当前合成图成为草图 v1。

### 5.4 底图

- **放上底图**：
  - 把参考墙、截图墙或版本链里的图拖到画布区域，或者选中图按 B。
  - 在画板里按 ⇧⌘V 粘贴。
  - 在新建画布时选好。
- **调整状态**：放上后，这一层固定在最下方，不透明度 30%，锁定，并进入调整状态：可以拖动，拖四角缩放，也可以点"适合画布"或"铺满"。按 ↵ 完成。
- **导出**：底图默认不参与导出，不参与 ⌘C 复制，也不会发给 AI。在层上可以勾选"导出时包含"。
- 把图拖到图层面板上，则作为普通的新图层。

- **开出一轮**：画板里有还没冻结的改动时，先自动存一版，保证记录里的"输入草图"就是发出去的那张；然后开出新的一轮。

| 图的来源 | 默认 |
|---|---|

- **风格词、负面词**从风格包读取；**规格句**取本实体的尺寸字段。这里只能勾选或取消，要改就点"改 ›"跳到风格包或规格。

- **限定色板**：风格包里打开了"限定色板"时，文字里附上色值。
- **用途、视角、约束**：都是项目片段里的标签。用途和视角单选，约束多选，每种实体类型各自记住上次的选择。预览实时拼出最终文字。

### 5.6 发出

1. **导出图片**：勾选的图写到 `.gamepanl/handoff/<id>_round-N/` 临时目录，本轮结束后清理。
   - 像素图用最近邻放大到长边至少 512px；长边超过 2048px 的缩小。
   - 画布很大时，"拖全部"手柄显示"准备中"，暂时不能拖。
2. **切到浏览器**：面板自动变成交接小窗（§5.7）。
3. **拖图**：按住"拖全部"，把勾选的图一次拖进网页的对话框，图会按顺序上传。拖单张缩略图就只拖那一张。
4. **复制文字**：点"复制文字"（⇧⌘C），回到网页 ⌘V，然后发送。最后一次复制的文字，就是本轮存档的提示词。
5. **兜底**：不方便拖的时候用 [接力复制]。每按一次，把下一项放进剪贴板，顺序是图1、图2…、文字；按钮上显示"下一项：图2"，用户在网页里每次按 ⌘V 即可。

### 5.8 收图

- **主推的收法**：在网页里右键图片，选"复制图片"。
  - 本轮进行中、小窗又可见时，小窗监听剪贴板，出现新图片就自动收为候选，小窗上显示"● 正在收图"。
  - 本轮结束后停止监听。设置里可以关掉自动收。
  - 自动收只收"新出现的、不是 GamePanl 自己放进去的"图片，所以接力复制放进剪贴板的图不算。和本轮已有候选重复的图也不收。
- **其他收法**：在小窗或面板里 ⌘V；从访达一次拖入多张；从浏览器直接拖。
- **收到之后**：
  - 图立刻依次成为候选 A、B、C，角标显示"GPT · 14:32"。
  - 同时提示"已收为 分裂史莱姆 · 第 1 轮 候选 A · ⌘Z 撤销"。
  - 先显示半透明缩略图，写盘完成后变实。
- **写盘位置**：`codex/<type>/<id>/versions/ai/round-N/A.png`，本轮信息写进同目录的 `round.json`（§4.4）。
- **尺寸不符**：候选标黄（▲ 1024≠32），旁边是 [按规格重描]（§4.6）。
- **在面板里的候选上可以直接操作**：
  - "选这张"：在版本链里标为选定。
  - "基于这张再来一轮"：开始新一轮，这张作为图1，作用说明取"参考说明 › 基于这张修改"，描述框清空，等你写修改意见。
  - 把候选拖进画板，就是作为底图描改。
- **关闭面板**：本轮不结束（→ §4.4 轮次）。

### 5.9 为什么这样发、这样收

1. 系统剪贴板一次只能放一张位图，而且网页的输入框粘贴时通常只取图或文字中的一种。所以分两步：图片靠拖（可以一次多张），文字单独复制。
2. 网页那种拖拽带不出文件到别的应用，只能用 Electron 的原生文件拖拽（支持多个文件）。所以发出前要先把图写到 `.gamepanl/handoff/`。
3. 拖拽要求两个窗口同时可见，而浏览器常常是全屏的。所以用系统浮动面板类型的小窗，全屏空间里也能看到。
4. 从浏览器把图拖回来，经常只带过来一个链接；而 Chrome 和 Safari 的"复制图片"都会把 PNG 放进剪贴板。所以主推"复制图片"，并由小窗自动收。

### 5.10 空状态、错误、边界

- **空状态**：
  - 新画布：中央淡字"B 画笔 · 拖图进来作底图 · ⇧⌘A 交给 AI"，落第一笔后消失。
  - 第一次交给 AI：底部三步条带说明文字，完成第一轮后收成一行。
  - 没有风格词：显示"风格包里还没有风格词 [去填]"，预览里不出现这一行。
  - 从实体卡进入、还没有草图：图片区显示"只复制文字即可"，第 1 步自动跳过。
  - 候选区为空："网页里右键图片 → 复制图片，会自动收进来"。
- **错误**：
  - 在面板里 ⌘V 时剪贴板里是文字：提示条「剪贴板里是文字 · [作为本轮备注]」。剪贴板里什么都没有：提示去网页里复制图片。
  - 拖进来的只有链接（Gemini 常见的 blob 链接）：先尝试读取，读不到就提示"右键 → 复制图片"。
  - 写盘失败：候选标红，给出 [重试] 和 [另存到…]，图片保留在内存里不丢。
  - 没检测到压感笔：显示灰字"按固定粗细"。
- **边界**：
  - 同一张图收两次：提示"已在候选 B"，不重复收。
  - 发出后又改了草图：本轮记录的是冻结版本，不受影响。
  - 复制文字后又改了选项：提示"与已复制的不同 [重新复制]"。
  - 手改最终文字后：各选项变灰，不再自动拼接；点 [恢复自动] 放弃手改。
  - 本轮进行中实体被删除：候选跟着实体进回收站，小窗关闭。
  - 改了规格或风格包：画板的网格、色板和交接文字立即跟着变；已经发出的轮次不变。

  - 实体换了定稿，节点缩略图自动更新。

  - 实体进了回收站：引用节点显示为灰色、垃圾桶图标，带 [恢复] [转为普通节点]。

- **打开**：
  - 双击引用节点，或者选中后按 ⌘O，打开实体。
  - 普通节点里的链接块用 ⌘点击跳转，⇧⌘点击在右栏打开。
  - 双击普通节点是进入编辑。

通用规则见 §1.10。导图和正文里的补全多一组"导图节点"：

```
逃亡：躲进 [[1-2|
┌────────────────────────────────────────────────┐
│ [图] 1-2 之前的笔记       笔记 · 关卡      ○    │
│ 导图节点                                        │
│ [节] 1-2 洞窟      关卡路线 › 世界1 › 1-2 洞窟  │
│ ＋ 新建「1-2」… ▸                               │
└────────────────────────────────────────────────┘
选中导图节点后，原地提示：
┌ 升级为实体卡并引用？ 类型 [7 关卡 ▾]（由"关卡路线"推断） ↵ 升级 · Esc 取消 ┐
```

- **选中导图节点并按 ↵**：该节点升级为实体卡，原节点原地变成引用节点，当前位置插入 [[1-2 洞窟]]。两处从此指向同一张卡。

**升级为实体卡**：在导图里选中节点按 ⇧⌘E。

```
┌ 升级为实体卡 ──────────────────────────────┐
│ 名称  背叛者·灰鸦                            │
│ 类型  1角色 2怪物 3Boss 4道具 5技能 6场景    │
│       7关卡 8界面 9剧情节点✓  其他：打字筛选 │
│ 方面  叙事（来自这张导图）                   │
│ ⚠ 已有「灰鸦」（怪物）· 改为引用已有的        │
│                          [取消] [升级 ↵]    │
└─────────────────────────────────────────────┘
```

- **类型**：按导图推断（故事线 → 剧情节点，关卡路线 → 关卡，玩法结构 → 机制），数字和类型的对应和 §4.2 相同。
- **升级后**：
  - 节点第一行成为名称，其余几行成为实体卡的设定正文。
  - 节点里的图成为草图 v1；如果是"画一张"画的，画板一起搬过去。
  - 节点的状态成为卡片状态（节点没有状态时为"想法"）。
  - 原节点原地变成引用节点，它的子节点保持不动。
- **多选升级**：⇧点选多个节点后按 ⇧⌘E，一次生成多张卡，类型统一选一次。
- **提示条**：「已创建实体卡 · ⌘Z 撤销」。撤销时节点恢复原样，新建的卡片进回收站。

### 6.4 方面页与画布位

V1 的方面页只搭骨架：本方面文档、按标签聚合的条目列表、一个画布位，以及个别方面的专属卡片。

```
叙事 ──────────────────────────────────────────────────────── ⋯
[本方面文档：世界观设定]                        （aspects/narrative.md）
[条目：叙事标签 · 12 项    筛选：全部 实体 笔记 导图]
┌ 画布 · 故事线 ─────────────────────────── 打开编辑 ↗  ⋯ ┐
│   （只读的实时缩略图，适应宽度，高 360px）                  │
└──────────────────────────────────────────────────────────┘
画布位为空时：┌ 挂一张导图   [故事线模板] [空白] [选已有…] ┐
```

- **专属卡片**：
  - 美术页：风格包卡。
  - 技术与测试页：规格卡。
  - 发行页：嵌入截图墙的"商店"视图。
- 方向页就是主题和支柱的编辑处。
- 每个方面页的画布位只挂一张主导图。同标签的其他导图出现在条目列表里（用"导图"筛选）。
- 画布位右上的"⋯"菜单可以更换或取下主导图；取下只解除挂载，不删除导图。
- 内置模板只有四个：故事线（主线 → 第一幕 / 第二幕 / 第三幕）、关卡路线（世界1 → 1-1…1-4 → Boss）、玩法结构、空白。

### 6.5 核心流程

**故事线**：

1. 在叙事页的画布位点 [故事线模板]，生成三层骨架，打上叙事标签并挂到这里，进入编辑器，选中"第一幕"。
2. 按 Tab 新建子节点，直接进入编辑，输入"村庄被袭"。按 ⇧↵ 换行，输入"动机：找回 【【莉"，在补全里选"＋ 新建「莉娜」"，按 → 选"角色"，按 ↵，行内建卡。
3. 按 Esc 结束编辑。按 ↵ 新建同级节点"逃亡"。
4. 给节点放图，有三种办法：
   - 右键"画一张"，进入画板，画完按 ⌘[ 或点面包屑回来，图自动放进节点。
   - 在画板里按 ⌘C，回到导图选中节点按 ⌘V。
   - 从访达或版本区把图拖到节点上。
5. 选中节点按 2，设为待做，色条变成蓝色粗线。
6. "背叛者"越写越重要：选中它按 ⇧⌘E，按 ↵ 升级为剧情节点卡。
7. 双击引用节点跳到实体卡，按 ⌘[ 回到导图，视口位置和选中的节点都恢复。

**关卡路线**：

1. 在关卡页新建导图，选关卡路线模板。也可以从笔记里复制缩进列表，在导图里 ⌘V，每一行生成一个节点，缩进决定层级，行里的 [[链接]] 保持为链接。超过 50 行时先确认。
2. ⇧点选 1-1 到 1-4，按 ⇧⌘E，按 7 选关卡，按 ↵，一次生成 4 张关卡卡。
3. 1-1 做完了，在导图里按 4（或 ⌘↵）。状态存在实体上，图鉴和关卡页的列表同步变绿。
4. 世界 1 做完了，选中它按 ⌘/ 折叠，节点显示"▸ 5 · 3/5 完成"。按 ⌥⌘/ 把整张导图折叠到第二层。
5. 分支太大时，右键"移到新导图"：这个分支移到一张新导图，原位置留下一个指向新导图的引用节点。新导图继承原导图的方面标签。

### 6.6 被引用处

同一份数据显示在两个地方：

- **右栏**：紧凑列表，最多 5 条，后面接"共 N 条 ›"。
- **实体卡底部**：完整列表，点右栏的"共 N 条 ›"滚动到这里。其他条目（笔记、导图、资产）只在右栏显示，点"共 N 条 ›"时，右栏的被引用处段就地展开成完整列表。

统一分成四组：

| 组 | 内容 | 每行显示 |
|---|---|---|
| 挂在这里 | 整理收件箱时挂到这个实体的笔记 | 勾选圈（可以直接打勾）、标题、来源和日期 |
| 导图 | 引用了它的导图节点 | 节点路径，如"故事线 › 主线 › 第一幕 › 村庄被袭" |
| 笔记和实体正文 | 正文里的 [[链接]] | 来源名，加上链接前后各约 20 个字 |
| 字段引用 | 截图的"关卡 / 系统"、资产的"所属实体"、实体的关联字段（出现关卡、掉落等） | 来源名和字段名 |

- 同一个来源里出现两次，就列两行。
- 点任意一行就跳转，按 §1.14 定位。
- 一条引用都没有时显示"还没有地方提到它"，这个条目会出现在"无引用"筛选里。

### 6.7 多张导图怎么组织

- 导图是一种条目，有方面标签，可以被 [[链接]] 引用，存为 `maps/<map-id>.json`，配图放在 `maps/<map-id>_images/`。
- 典型配置：叙事挂故事线，关卡挂关卡路线，玩法挂玩法结构。
- 导图不能引用自己。

### 6.8 空状态、错误、边界

- **空状态**：
  - 新导图只有根节点，画布底部淡字提示"Tab 子节点 · ↵ 同级 · [[ 引用图鉴 · 粘贴图片"。第一次加了子节点后，提示不再出现。
  - 补全里没有匹配项时，只显示"新建"那一行。
- **加载**：打开导图时先画出节点，图片位置显示灰色占位，图片按需加载。
- **错误**：
  - 节点图片在外部被移走：显示"图片丢失 · 重新指定"。
  - 导图文件在外部被改动、无法解析：按 §1.15 处理。
- **边界**：
  - 删除带子节点的节点，会连同子树一起删除，提示"已删除 6 个节点 · ⌘Z"。
  - 删除引用节点不会删掉实体。
  - 根节点不能删。
  - 删除还有被引用处的实体时不弹确认，提示条里写"被 N 处引用"。
  - 往引用节点粘贴图片：图片进该实体的版本链（成为草图，或本轮的候选），提示可以撤销。引用节点本身不单独存图。
  - 节点拖到空白处会弹回原位（V1 没有游离节点）。

### 6.9 快捷键与拖放

| 操作 | 按键 |
|---|---|
| 新建子节点 / 同级节点 | Tab / ↵（选中状态下） |
| 进入编辑 / 结束编辑 | 空格或双击普通节点 / Esc |
| 编辑中换行 / 升一级 | ⇧↵ / ⇧Tab |
| 移动选中 | ↑↓←→ |
| 在同级中调整顺序 | ⇧⌘↑ / ⇧⌘↓ |
| 折叠或展开 / 全部折叠到第二层 | ⌘/ / ⌥⌘/ |
| 设状态 / 清除状态 / 完成 | 1–4 / 0 / ⌘↵（搁置和砍掉在 ⇧⌘S 菜单里） |
| 升级为实体卡 | ⇧⌘E |
| 打开引用 / 后退 / 前进 | ⌘O、双击、⌘点击 / ⌘[ / ⌘] |
| 复制为链接 | ⌥⌘C |
| 删除节点 / 撤销 / 重做 | ⌫ / ⌘Z / ⇧⌘Z |
| 适应窗口 / 缩放 | ⌘0 / ⌘+ ⌘− 或捏合 |
| 多选 | ⇧点击，或按住 ⌥ 在空白处拖出选框 |

- **拖节点**：拖到另一个节点上，目标描边高亮，松手后成为它的子节点；拖到两个同级节点之间，出现插入线，用来调整顺序；按住 ⌥ 拖是复制。
- **从访达拖图片**：拖到没有图的节点上，设为节点配图；节点已经有图时，和粘贴一样新建一个子节点放这张图（§1.7）；拖到引用节点上，图进该实体的版本链；拖到插入线上，新建一个带图的节点。
- **右键菜单**：
  - 普通节点：画一张 / 升级为实体卡 / 移到新导图 / 复制为链接。
  - 引用节点：打开 / 画草图 / 交给 AI / 转为普通节点。

### 6.10 衔接

- **进来**：
  - 方面页的画布位。
  - ⌘K 搜导图名或节点文字，⌘K `+导图`。
  - 任意 [[导图]] 链接。
  - 被引用处的某一行（进来后定位到那个节点）。
  - 首页的 [开始排故事线]。
- **出去**：
  - 实体卡和笔记：⌘O、双击、⌘点击；⌘[ 返回。
  - 画板：普通节点"画一张"，引用节点"画草图"。
  - 交给 AI：引用节点右键"交给 AI"。

### 7.3 改一个被引用的值

改的时候原位弹出：

```
 角色 [48×48▏]
 ┌─────────────────────────────────────────────────────────────┐
 │ 会影响：之后新建画布的"角色"预设；交给 AI 尺寸行；3 个片段    │
 │ 不会改：已有 5 张画板（仍是 32×32）、已归档的文件             │

确认后生效，记入变更记录，⌘Z 可以撤销（整组写入算一步）。

### 7.4 风格包

风格包是风格词、负面词、样张唯一存放的地方，另有一个"限定色板"开关：打开后，交给 AI 时附上项目规格里色板的色值。画板、交给 AI、右栏都从这里读取风格词。

```
风格包 · 雾港                                                    [存到我的库]
主风格    像素 16-bit（来自库 ›）
风格词    [pixel art] [16-bit] [limited palette] [side view] [+]      [复制]
负面词    [blurry] [3d render] [text] [watermark] [+]                 [复制]
样张      [图] 参考线条、配色与明暗，不参考内容和构图 ✎   [图] …   [+ 拖入 / ⌘V]
限定色板  ☑ Endesga 32（交给 AI 时附上色值）
── 交给 AI 时会带上 ───────────────────────────────────────────────────────
风格：pixel art, 16-bit, limited palette…  避免：blurry, 3d render…  色板：#1a1c2c …
```

- **风格词和负面词**是标签块：输入后回车添加，拖动调整顺序（顺序就是复制出去的顺序），⌫ 删除最后一个。
- **样张**最多 4 张，来源可以是参考墙、图鉴定稿、访达拖入或 ⌘V。每张附一句作用说明，默认取「参考说明 › 风格样张」，可以改。
- 空状态：按项目是 2D 还是 3D，推荐 4 张风格卡，另有"自己写风格词"。

### 7.5 项目片段与参考说明

项目片段是交给 AI 时可以勾选的文字块，分四类：用途、视角、约束、参考说明。它们是从库加入的副本，或在本项目里新建的，存在 `library/` 下（§9）。

- **可复制块**里可以用变量：输入 `{` 弹出补全，比如 {分辨率}、{瓦片}、{PPU}、{尺寸:角色}、{色板色值}。另有 {尺寸}，在交给 AI 时代表本实体的尺寸字段。
- **参考说明**定义每类图的默认作用说明，**只在这里定义一次**，交给 AI 和风格包都引用它：

| 参考说明 | 默认文字 |
|---|---|
| 本次草图 | 保持造型、姿态和构图，线条可以重画 |
| 本实体定稿 / 已选定 | 保持外观和配色一致 |
| 风格样张 | 参考线条、配色与明暗，不参考内容和构图 |
| 同类型定稿 | 统一比例和画风 |
| 参考墙图（没写"参考它什么"时） | 只参考画风，不照搬内容 |
| 基于这张修改 | 在这张基础上修改，保留整体造型 |

- 空状态："在交给 AI 里勾选过的片段会出现在这里"，附一个浏览生图风格库的按钮。

### 7.6 浏览、复制、加入项目、存到我的库

- **搜索**：⌘F 或 /，搜标题、摘要、可复制块和标签，中英文都行（"pixel"能搜到像素风，"16×16"能搜到瓦片）。
- **复制**：↑↓ 选条目，点 ⧉ 或按 C 复制，变量已经换成当前值，提示"已复制 · {尺寸:角色}→32×32"。
  - 变量没定时，按钮显示"复制（1 个未定）"，点击弹出「角色 [__] ↵ 填入规格并复制」；按 Esc 跳过该变量直接复制，并提示缺哪一项。
  - ⌥点击 ⧉ 复制原文，保留 {变量}。
  - L 切换中文 / EN 版本。
- **加入项目**（⌘↵）：按钮上直接写明加入后去哪里。

| 条目类型 | 加入后 |
|---|---|
| 起步组合、分辨率、尺寸、命名、UI、音频、3D | 写入规格的对应字段（尺寸成为新的命名尺寸） |
| 调色板 | 写入规格的色板 |
| 美术风格 | 成为风格包的主风格（带风格词、负面词、推荐视角、样张） |
| 视角 | 写入风格包的视角 |
| 生图片段（用途、视角、约束、参考说明、负面词） | 复制成项目片段 |
| 设计原则 | 以引用块的形式追加到「美术」方面文档 |

   - 目标为空时直接写入，按钮变成"✓ 已加入 · 打开副本"。
   - 目标已有内容时：字段逐行显示"当前 → 新"，每行可以勾选保留；片段已存在时选"打开已有"或"再加一份"；已有主风格时选"替换"或"只追加风格词"。
   - 副本和库条目不再关联，可以随便改；副本上保留一行"来源 ›"，可以回到库条目。
- **存到我的库**：
  - 项目规格用「存为规格组」，风格包用「存到我的库」，项目片段用右键菜单，内置条目用 ⌘D。
  - 弹框填名称（默认带项目名）和标签，↵ 保存，重名时选覆盖或另存。
  - 我的库的条目在空状态和库选择器里排在内置条目前面。
  - 在内置条目上打字时，提示"内置条目只读 · ⌘D 另存到我的库后编辑"。

### 7.7 在用处调用

- **新建画布**（§5.2）：先列规格里的尺寸，网格、色板、锚点标记自动带上；从规范库选的尺寸默认只用于这一张。
- **交给 AI**（§5.5）：自动带风格词、负面词、尺寸行、样张和限定色板。片段区是项目片段的开关，按用途、视角、约束分组；末尾「+ 从生图风格库添加」，选中后复制进项目片段并勾上。每一项旁边有"改 ›"，跳到规格、风格包或片段。
- **文件命名**（§1.18）：资产行按规则预填文件名。
- **右栏**：查看实体时，相关规格段显示"小型怪物 32×32 · 锚点 底部中心 · spr_fenlieshilaimu_*"，相关风格词段显示风格词标签块，点一下就能复制。

### 7.8 空状态、错误、边界

- **错误**：
  - `spec.json` 在外部被编辑后解析失败：顶部黄条"spec.json 第 12 行格式错误，当前显示上次可用的版本（只读）"，提供 [在编辑器中打开] 和 [用此版本覆盖]。
  - 内置库文件缺失：启动时从安装包静默恢复。
  - 我的库所在目录不可用（比如外置盘拔了）：黄条和 [重新定位]，我的库条目灰显，内置库照常可用。
- **边界**：
  - 尺寸输入 16x16、16*16、16 16 都识别成 16×16；只填一个数字时，按正方形处理。
  - 像素风搭配非整数缩放（比如缩放到 1080p 不是整数倍）时，显示黄色提示，但不拦截。
  - 改命名规则只影响之后的文件，页面显示"37 个文件沿用旧规则 · 去资产表按规则重命名 ›"。
  - 删除被引用的自定义字段：直接删除，提示条"被 N 处引用 · ⌘Z 撤销"；引用处显示灰色的"已删除"标签块，带垃圾桶图标。
  - 关掉"本项目含 3D"时，只隐藏 3D 区，不删除已经填的值。
  - 没有打开项目时，「加入项目」按钮置灰。

```

### 8.4 资产表

一行就是游戏里要用的一个资产。默认表格视图，按所属实体分组。

```
┌ 资产（表格，按所属实体分组）──────────────────────────────────────────────────────────────────┐
│ ☐  图  文件名                           类型  所属实体    规格               阶段          来源    授权   │
├───────────────────────────────────────────────────────────────────────────────────────────────┤
│ ▾ 分裂史莱姆 · 3                                                                              │
│ ☐  ▣   spr_fenlieshilaimu_01  主图      图片  分裂史莱姆  小型怪物 32×32     定稿·来自版本链 AI·GPT  AI生成 │
│ ☐  ▣   anim_fenlieshilaimu_hit_01 ↗源   动画  分裂史莱姆  小型怪物 32×32     修改          自制    自制   │
│ ☐  ┆   sfx_fenlieshilaimu_split_01      音效  分裂史莱姆  音效 wav           占位          —       —      │
│ ▾ 未挂实体 · 1                                                                                │
│ ☐  ▣   bat_fly.png   建议名 …            动画  —           角色 32×32 ▲       定稿          素材包  未知   │
└───────────────────────────────────────────────────────────────────────────────────────────────┘
```

- **两个文件位**：
  - **文件**：导出的成品，复制进 `assets/<type>/`，按命名规则命名（导入的保留原名）。
  - **源文件**：.aseprite / .psd / .kra / .blend 等，默认只记路径、不复制，行内标"↗源"。
- **缩略图**：先用文件；没有文件就用源文件里自带的预览图；都没有就显示格式图标。还没有文件的占位行显示虚线框。
- **规格**：从项目规格里选。图片实际尺寸和规格不一致时标 ▲。
- **阶段**：所有资产共用一套阶段：占位 → 草图 → AI 稿 → 修改 → 定稿 → 已进工程。
  - 用 ⇧⌘S 或点阶段格改。
  - 主图行的阶段只读（§4.7）：阶段格不可点，⇧⌘S 菜单里只有"已进工程 / 取消已进工程"，看板里只能拖到"已进工程"列；把图片或文件拖到主图行上，等同拖进实体卡版本区（§4.4）。
  - 字体和素材包新建时默认"定稿"，其他阶段照常可选。
- **不同类型的显示方式**：
  - 音效显示 ▶，可以直接试听。
  - 字体用字体本身渲染一段示例文字。
  - 素材包（文件夹或 zip，按引用挂上）用包里前 4 张图拼成缩略图。
- **授权**：可选自制、AI 生成、CC0、CC-BY、付费商用、仅个人、未知，另记署名要求和链接。"未知"标红。
- **预设视图**：全部、我在做的（阶段 ≠ 已进工程）、授权待查。
- **来源**：自制、AI（工具和日期）、素材包、导入。
- **打开**：资产行没有详情页。↵ 或双击在右栏展开属性；⌘O 用默认程序打开文件；右栏里的 [打开源文件] 用默认程序打开源文件。
- **没有版本**：资产行只保存当前文件，替换时旧文件进回收站。

**从占位到进工程**：

1. 在实体卡的"相关资产"里点 [+资产]，或在资产表按 ⌘N。新行自动填好类型、所属实体和规格，阶段为"占位"，文件名以灰字预览，例如 `anim_fenlieshilaimu_hit_01`。
2. 把 slime.aseprite 拖到这一行，它以引用方式挂上，行内出现"↗源"。
3. 把导出的 PNG 拖到同一行，它被复制进 `assets/anims/`，并按规则命名。阶段不会自动变，阶段格闪一下，提醒手动推进。
4. 源文件在外面改过时，面板回到前台会自动刷新缩略图，右栏显示"源文件 10 分钟前更新"。
5. 把这一行拖到引擎的文件面板或访达，拖出去的是文件本身。拖完提示条「已拖出 1 个文件 · 标为已进工程 [是]」。

**按规则重命名**（批量栏）：只改选中的行，跳过已进工程的资产和所有源文件，先列出新旧文件名，确认后执行（§1.18）。

**单字母**：E 挂到实体、A 方面标签；改阶段用 ⇧⌘S。

### 8.5 空状态、错误、边界

- **资产表空状态**："这里放游戏里真正要用的文件，没做的也可以先建占位行"，下面三个按钮：[新建占位行] [挂源文件…] [导入文件夹…]。
- **加载**：第一次打开很大的文件夹时，显示"正在生成缩略图 320/1,284"，不影响其他操作。
- **错误与边界**：
  - 未知格式（如 .spine）：照样收下，显示格式图标，可以用默认程序打开。
  - 超大文件：单个文件超过 500 MB 时，建议改为引用。

  - 其余（未登记文件、文件缺失、索引损坏、重名、重复）按第 1 章处理。

## 9. 本地项目目录与存储（唯一目录表）

```
<project>/
├─ project.json              名称、主题、支柱、当前版本、方面（顺序、隐藏、各方面页画布位挂的主导图）、今日焦点和明天的焦点、停在哪里、已存视图、格式版本号

├─ notes/                    同上
├─ aspects/                  每个方面一个 .md（本方面文档）：direction gameplay narrative level art ui audio tech release
├─ codex/<type>/<id>/        <type> 为 character monster boss item skill scene level ui story-node mechanic（自定义类型用其英文 ID）；<id> 即实体的"文件名 ID"
│   ├─ <id>.md               字段在文件头，正文是设定正文
│   ├─ boards/<board-id>.board/  画板文件夹（描述 JSON + 每层 PNG + 预览 PNG）
│   ├─ versions/sketch/      v1.png v2.png …
│   ├─ versions/ai/round-N/  A.png B.png C.png（等分切为 A1.png…）+ round.json
│   └─ versions/edit/        v1.png v2.png …
├─ boards/                   未挂实体的画板（同时在收件箱生成一条指向它的条目）
├─ maps/<map-id>.json        导图
├─ maps/<map-id>_images/     导图普通节点的配图和"画一张"的画板
├─ assets/                   assets.json + sprites/ anims/ fx/ sfx/ fonts/ packs/
├─ screenshots/              screenshots.json + 按月子目录（2026-09/shot_0922-1403_v0.3.png）
├─ references/               references.json + 图片（保留原名，粘贴的叫 ref_0924-1432.png）
├─ library/                  从库复制进来的副本：风格包（含样张图）、项目片段
├─ _trash/                   回收站，每次删除一个文件夹：2026-09-24_1432_fenlieshilaimu/
└─ .gamepanl/                缩略图、搜索索引、索引备份、handoff/ 临时目录（删了会重建）

**项目之外**：

| 位置 | 内容 |
|---|---|
| `~/GamePanl/<project-id>/` | 新建项目的默认位置 |
| `~/GamePanl/my-library/` | 我的库（普通文件夹，可以自己备份） |
| `~/GamePanl/loose-notes/` | 还没有项目时的散记，并入第一个项目后清空 |
| 应用设置 | 最近项目列表、快速记录键、各项开关 |

**规则**：

- 目录名和文件名一律用英文（小写、连字符），不含中文和空格，方便命令行、git 和脚本处理；中文标题只写在文件内容和元数据里。左栏仍显示中文名，和目录一一对应：收件箱 `inbox/`、全部笔记 `notes/`、方面 `aspects/`、图鉴 `codex/`、资产 `assets/`、截图墙 `screenshots/`、参考墙 `references/`、库 `library/`、回收站 `_trash/`。停车场是视图，没有对应的目录。
- 图片和音频始终以原格式、原文件保存，不打包。
- 字段只写在两个地方：.md 的文件头，或者该文件夹里唯一的索引 JSON（`screenshots.json`、`references.json`、`assets.json`、`round.json`）。
- 每条内容有固定 id，改文件名、改实体名都不会断链接。
- 写入时先写临时文件，写完再替换原文件（§1.15）。
- 版本链里的文件用简单序号命名；只有 `assets/` 里的文件按命名规则命名（§1.18）。
- 定稿不在实体文件夹里另存副本，只在 `assets/sprites/` 生成主图行的那一份（§4.7）。
- 引用的外部文件（源文件、素材包）只记绝对路径和内容哈希，不复制，丢失时按 §1.15 重新定位。
- `.gamepanl/` 里的内容都可以重建。`handoff/` 下的临时图在本轮结束时清理。

- 一个节点放多张图，图片裁切和标注。
- 块级或标题级引用（`[[条目#段落]]`）、链接别名显示文字、未链接提及。
- 在笔记里嵌入可以实时编辑的导图；关系图谱、全局链接图。
- 从库套用叙事结构模板（只内置故事线、关卡路线、玩法结构和空白）。
- 把导图导出成图片、PDF、OPML；导图内搜索（统一用 ⌘K）。

**库与规格**

- 对比原版、恢复原版，库条目更新后同步到项目副本；在线更新库内容；库的打包导入导出。
- 自动批量改名（只提供资产表里手动触发的"按规则重命名"），画板跟着规格自动缩放。
- 按对象分的风格变体，一个项目多套风格包。
- 帧率、音频、3D 字段被其他模块自动引用（V1 只记录）。
- 在任意笔记里用变量显示实时值（只有片段、交给 AI 和命名会替换变量）。
- 可以自定义资产存放目录（固定为 `assets/<type>/`）。

**条目表、截图墙、参考墙、资产表**

- 时间线视图、矩阵视图、公式列、多级分组、多字段排序、看板数量上限、泳道。
- 在面板里截图或录屏、按商店尺寸裁切导出、改动前后对比、拍摄清单；商店视图的张数建议和尺寸检查。
- 参考墙的浏览器插件、整页网页抓取、以图搜图。
- 3D 模型旋转预览、音频波形、按资产类型定制阶段、自动同步到引擎目录、包体大小统计、跨项目素材仓库。
- 资产行的版本历史，以及源文件改动后自动记为新版本。
